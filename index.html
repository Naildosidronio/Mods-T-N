Importante sobre PS4 e PS5

As modificações são feitas no save da versão de PS4. Se o jogo tiver versão PS4 e versão PS5, siga o processo abaixo antes de solicitar o cheat.

🎮

1 — Cheat em jogos com PS4 e PS5

Os cheats/modificações são feitos na versão de PS4 do jogo.

Exemplo: Nioh 2 possui uma versão para PS4 e outra para PS5. Para a gente fazer a modificação, você precisa começar o seu progresso na versão de PS4. Depois que a MODS-TN terminar as modificações no seu save de PS4, você entra novamente no jogo e faz a transferência/migração do save da versão PS4 para a versão PS5.

01COMECE NO PS4Crie ou continue o progresso na versão PS4 do jogo.
02FAZEMOS O CHEATA MODS-TN modifica o save da versão PS4.
03RECEBA O SAVEVocê recebe o save já modificado.
04TRANSFIRA PARA O PS5Depois, faça a transferência do progresso para a versão PS5.

Exemplo prático — Nioh 2: Nioh 2 PS4 → começa o progresso → enviamos/pegamos o save → fazemos as modificações → devolvemos o save → você transfere o progresso para Nioh 2 PS5.

▣

2 — Método 1: login via QR Code

Esse método é para quem prefere que a gente acesse a conta para pegar os dados necessários.

  1. A MODS-TN inicia o processo de login na sua conta.
  2. Você não precisa passar a senha da sua conta.
  3. Você também não precisa passar senha do Gmail/e-mail.
  4. O login é feito por QR Code.
  5. Você escaneia o QR Code no seu aparelho e dá a permissão para o login.
  6. Depois da autorização, a gente continua o processo para acessar o save e fazer o serviço.
✓ SEM ENVIAR SENHA DA CONTA OU DO GMAIL
💾

3 — Método 2: save pelo pendrive

Se você preferir não usar o método de login, pode mandar o save diretamente para a gente.

  1. No seu console, copie o save do jogo para um pendrive.
  2. Depois que o save estiver no pendrive, conecte o pendrive em um PC ou em um celular usando cabo/adaptador OTG.
  3. Dentro do pendrive, localize a pasta PS4.
  4. Compacte/zip a pasta PS4 inteira.
  5. Depois de criar o arquivo ZIP, envie esse arquivo para a MODS-TN pelo WhatsApp.
